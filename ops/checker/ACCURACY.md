# 査定精度の調査（2026-11-01）

きっかけ: のぼるさんの自宅（中古戸建て・山口県宇部市際波・2000年築・土地238㎡・建物172㎡、購入 1,780万円）で、査定が 1,049万円。

## 使ったデータと方法
- 学習データと同じ国土交通省の取引価格（2021年第4四半期〜2025年第4四半期、`chi-pao/-` のリリース `ai-training-data-v1` の `All_20214_20254.zip`）。
- 対象: 「宅地(土地と建物)」かつ用途に「住宅」を含む 391,881件。調停・競売・関係者間・隣地購入・瑕疵・取壊し前提の取引は除外。
- サイトと同じ計算（`checker-site/engine.mjs`・`model-runtime.mjs`・モデル .dat）を Node で動かして、サイトの表示と同じ値（のぼるさんの家で 1,049万円、入力例で 3,078万円）を再現してから測定。
- テスト: 2025年の取引から無作為に 20,000件。**今のモデルは2025年の取引も学習に使っているため、この比較は今のモデルに有利**。

## 結果
| 方法 | 誤差の中央値 | 実際の価格が査定の±20%以内 |
|---|---|---|
| 今のモデル | 25.0% | 42% |
| 近隣の類似取引（同じ市区町村で築年・土地・建物が近い10件、2024年までのデータのみ） | 25.1% | 42% |
| 両方の平均 | 24.3% | 43% |
| 今のモデル ×1.08（時点補正） | 23.9% | 43% |

- **2025年の実際の価格は、今のモデルの査定より中央値で 9% 高い**（実際/査定 = 1.09）。モデルは査定時点を「2026年」として計算するが、学習データは2025年まで。価格の上昇分が反映されていない可能性が高い。
- **同じ条件の家でも実際の価格の幅が大きい**。査定に対する実際の価格は、真ん中の半分が 0.86〜1.40倍、80% が 0.55〜1.92倍に散らばる。入力項目（地域・広さ・築年など）だけでは、リフォームの有無・建物の状態・道路や土地の形などの差が分からないため。
- 方式を変えても（近隣の類似取引）誤差はほぼ同じ。**計算方法より、入力項目と表示の仕方を改善する余地が大きい**。

## のぼるさんの家
- 宇部市で築年・土地・建物が最も近い取引10件（2022〜2025年）: 480万〜2,200万円、中央値 1,100万円、真ん中の半分は 870万〜1,675万円。
- 1995〜2005年築・建物140〜200㎡に絞ると14件で中央値 1,800万円。どの取引を「近い」とみなすかで大きく変わる。
- 1,780万円での購入は、この地域の似た家の取引の範囲内（上のほう）。1,049万円の査定は、似た家の中央値に近い。**査定が大きく間違っているというより、1つの数字で示していることが問題**。

## 改善案（効果の大きい順）
1. **価格帯で示す**: 「参考査定 1,049万円」だけでなく「似た家の取引の多くは 900万〜1,470万円」のように幅を出す（上の分布から計算できる）。1つの数字より誤解が少ない。
2. **近隣の実際の取引事例を表示する**: 同じ市区町村で築年・広さが近い取引を数件（価格・広さ・築年・時期）。利用者が自分で判断でき、信頼につながる。出典「国土交通省 不動産情報ライブラリ」を明記。
3. **時点補正**: 2025年の実際との差（約9%）を補正する。誤差中央値 25.0% → 23.9%。
4. **入力項目を増やす**: データにある「前面道路の幅員」「土地の形状」「間口」を任意入力にして学習に加え、効果を測る。
5. ~~町名の書き方をそろえる~~ → **対応済み（2026-11-02）**。`tools/build_town_aliases.py` で全国の町名リストと取引データの町名を照合し、`checker-site/town-aliases.json`（1,188市区町村・13,923件）を作成。サイトで選んだ町名を、モデルが学習した名前に変えて渡す（画面の表示は選んだ町名のまま）。
   - 照合: 「大字」「字」の有無、漢数字と数字（月寒東二条→月寒東２条）、旧字体（弥富通→彌富通）、取引データの方が大まかな場合は、町名の先頭が一致する最も長い地区（大久保町八木→大久保町）。
   - 全国の中古戸建ての取引で、取引の町名をサイトから選べる割合: 87.7% → 98.4%。
   - 2025年の取引のうち対応表で初めて一致する 9,053件: 誤差中央値 27.6% → 27.4%。金額への効果は小さく、主な効果は「学習時にない町名」の誤表示がなくなること。

どの改善も、2025年の取引で今のモデルと比べてから採用する。
