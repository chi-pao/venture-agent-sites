### 冒頭2秒のセリフ（2パターンを作って比べる）
- A: 「この家、高いの？安いの？」
- B: 「2,480万円。即決していいの？」

同じ動画で冒頭だけ変えた2本を、日をずらして投稿し、最後まで見られた割合を比べる。

## 画面に映すチェッカーの結果（実際の計算結果）
架空の物件を、実際のチェッカー（https://okaidoku-checker.pages.dev 、2026年11月更新モデル）で査定した値。作った数字ではない。
- 入力: 中古戸建て / 埼玉県所沢市（町名なし・駅徒歩は空欄） / 販売価格 2,480万円 / 2008年築 / 土地 120㎡ / 建物 95㎡
- 結果（2026-11-03、2026年11月・2回目のモデル）: 参考査定価格 **2,011万円**、判定「割高の可能性」（−23.4%）。価格の幅では「相場の範囲内」（同じような家の半数が 1,709万〜2,614万円）
- 以前の結果: 2,622万円・相場に近い（2026-11-02 のモデル）。モデルの更新で変わったため、話の流れを「割高かも？→でも相場の範囲内→現地で確かめよう」に変更
- モデルを更新したら、撮影前にもう一度査定して数字を確かめる（旧モデルでは 2,126万円だった）
- 画面録画は、のぼるさんか Claude Code がこの入力で実際に操作して撮る（ChatGPT に結果画面を描かせない）

## 守ること
- 登場人物はすべて架空。Instagram・TikTok・YouTube の「AIで作成」表示を付ける
- 通帳の金額は映さない（ぼかす）。「この年収なら買える」など、お金の助言に見える表現は入れない
- 「お得な家が見つかる」「損しない」と言い切らない。「参考の価格」「判断の材料」と表現する
- 物件ページは架空のもの。実在の不動産サイトの画面・ロゴは使わない
- 広告リンクは入れないので PR 表記は不要（広告を入れる場合は冒頭に「PR」）
