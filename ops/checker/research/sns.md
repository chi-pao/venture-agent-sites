# お買い得物件チェッカー SNS集客・運用レポート

- 対象: https://okaidokucyekka.streamlit.app （中古住宅・中古マンション・一戸建ての提示価格を、国交省の不動産取引データに基づく参考価格と比べる無料ツール）
- 体制: 投稿・画像・動画の制作と投稿作業 = ChatGPT ／ 承認 = のぼるさん（個人運営・広告費ゼロ）
- 調査日: 2026-11-01
- 調査方法の制約: この環境では官公庁・プラットフォーム公式ページ（caa.go.jp、support.google.com、blog.youtube など）を直接開けなかった。出典はWeb検索の結果ページ（タイトル・URL・抜粋）で確認したもの。**公式原文は運用開始前にのぼるさんが一度開いて確認すること**（(G) 参照）。
- 表記ルール: 出典のある事実には [番号] を付けた。出典のない判断は「仮説」と明記した。

## (A) 結論

**最初に力を入れるのは「X」と「Instagram（カルーセル＋リール）」の2つ。** note は第3の「受け皿」として週1本だけ書く。

理由:

1. **Instagram**: 不動産の情報源として Instagram を使った人が「購入」で22.2%という調査がある（And Doホールディングス、2025年4月）[1]。戸建て建築者の調査でも Instagram と YouTube がよく参考にされたとされる[2]（ただし注文住宅寄りの調査で、中古購入者にそのまま当てはまるかは未確認）。保存されやすい「図解・チェックリスト型」のカルーセルが、本ツールの「相場の見方」と相性がよい（仮説）。
2. **X**: 投稿本文にURLを直接貼れ、ツールへ1タップで誘導できる。リンク付き投稿の表示抑制についてはX側が「1年以上前からそうした措置はしていない」と述べたと報じられている[3][4]一方、2024年にはマスク氏がリンクを返信に置く運用を勧めたとも報じられ[5]、評価は割れている。→ **「本文にリンク」と「返信にリンク」を両方試し、UTMで比較する**のが妥当（仮説）。テキスト中心でChatGPTの制作負担が軽い点も個人運営向き（仮説）。
3. **後回しにするもの**
   - YouTubeショート / TikTok: 動画制作負担が大きい。YouTubeショートは説明欄・コメントのリンクが2023年8月31日以降クリック不可[6]で、ツール誘導が弱い。Instagramリールで作った縦動画を、余力が出たら転用する（仮説）。
   - Threads: プロフィールにリンク最大5件・投稿にリンク可[7]で使えるが、住宅購入層の利用実態は確認できなかった。Instagramと同じアカウント系列なので、Instagram投稿の文字版を転載する程度に留める（仮説）。
   - Yahoo!知恵袋: 自サイト誘導・宣伝の可否を規約原文で確認できなかった[8]。確認できるまで**リンク付き回答はしない**。
4. **アフィリエイト（火災保険比較など）の置き場所**: SNS投稿にアフィリエイトリンクを直接貼るより、「SNS → ツール or note記事 → 比較サービス」の二段構えにする（仮説）。理由: (a) ASP・広告主ごとにSNS掲載の可否が異なる[9]、(b) 保険は「特定商品への誘導」が保険募集に当たり得る[10]ため、説明の厚みと表記を管理しやすい記事側に置く方が安全（仮説）。

## (B) 4週間の運用計画

前提: 本数は「個人で承認が回る量」として置いた**仮説**。伸び方の数字は置かない（予測しない）。

| 週 | X | Instagram | note | 目的 |
|---|---|---|---|---|
| 1週目 | 1日1本（計7本）＋固定投稿1本 | カルーセル3本＋プロフィール整備 | 0〜1本（ツールの使い方記事） | アカウントの土台作り。プロフィール・固定投稿・リンクを整える。UTM計測を開始 |

| 3週目 | 1日1〜2本 | カルーセル3本＋リール1本 | 1本（火災保険の基礎記事、PR表記付き） | 反応の良かった型を増やす。noteでアフィリエイト導線を試験 |

週ごとの型の配分（目安・仮説）:
- 1週目: 型①相場の見方 ×多め、型④使い方 ×1（固定投稿用）
- 2週目: 型①②③を均等
- 3週目: 2週目で反応の良かった型を倍、型⑤（保険・諸費用）を1本

1. 月曜: ChatGPTが翌週分の下書きをまとめて作成（本文・画像案・UTM付きURL）
2. 火曜: のぼるさんが (D) チェックリストで確認し承認
3. 予約投稿（Xは予約投稿機能、Instagramは予約機能を使用。仕様は各アプリで確認）

## (C) 投稿の型（テンプレート）5種類 ＋ ChatGPTへの指示文例

共通ルール（すべての指示文の先頭に付ける）:

```
【共通ルール】
- 日本の中古住宅・中古マンション購入検討者向け。専門用語には短い説明を付ける。
- 「必ず得する」「絶対お買い得」「格安」「掘り出し物」など断定・誇張表現は使わない。
- 参考価格は「国土交通省の不動産取引価格情報をもとにした目安」であり、査定・鑑定ではないと明記する。
- 実在の物件ページ（ポータルサイト等）の画像・写真・文章を転載しない。例に使う物件は架空と明記し、数字も架空と書く。
- 実在の人物・企業・口コミをでっち上げない。体験談は「よくある例（架空）」と書く。
- AIで作った画像・動画を使った場合は、その旨を下書きに記録する（投稿時に各SNSのAI表示を設定するため）。
- 出力: 本文、画像（スライド）ごとの文字案、ハッシュタグ案（Instagramは5個以内）、UTM付きURL。
```

### 型① 相場の見方の解説（X・Instagramカルーセル）
- 目的: 保存・フォロー獲得。ツールの「参考価格」という考え方に慣れてもらう
- 構成: 1枚目「その価格、高い？安い？ 判断の手がかり3つ」→ 2〜5枚目 築年数・広さ・駅距離・取引時期の見方 → 6枚目「自分の物件で確かめる方法」→ 最終枚「プロフィールのリンクから無料で比較」
- 指示文例:
```
【共通ルール】（上記）
型①のInstagramカルーセル（7枚）を作って。テーマ「中古マンションの提示価格が相場と比べてどうかを見る3つの視点（築年数・駅距離・取引時期）」。
1枚目は20字以内の問いかけ、各スライドは60字以内。最後のスライドは「プロフィールのリンクから無料で比較できます」。
キャプションは300字以内。末尾に「※参考価格は国交省の取引データに基づく目安で、査定ではありません」を入れて。
X用に140字以内の要約版も作り、URLは https://okaidokucyekka.streamlit.app/?utm_source=x&utm_medium=social&utm_campaign=w2_soba を使って。
```

### 型② チェックリスト（Instagramカルーセル・X画像1枚）
- 目的: 保存・共有
- 構成: 「内見前に確認する10項目」「価格交渉の前に見る5項目」など。最後の1項目を「提示価格を参考価格と比べたか」にしてツールへつなぐ
- 指示文例:
```
【共通ルール】（上記）
型②のチェックリスト投稿を作って。テーマ「中古一戸建ての購入申込み前に確認したい8項目」。
各項目は「□ 〜を確認した」の形で25字以内。8項目目は「□ 提示価格を参考価格と比べた」。
Instagram用にスライド4枚分（1枚目タイトル、2〜3枚目に4項目ずつ、4枚目は案内）と、X用の画像1枚版（項目のみ）を出して。
法律・税金に関わる項目は「詳しくは専門家に確認」と添えて。
```

### 型③ よくある失敗例（架空の事例）
- 目的: 共感・リーチ。「確認しておけばよかった」をツールの必要性につなげる
- 構成: 状況（架空と明記）→ 何を見落としたか → 次はどう確かめるか → ツール紹介
- 避けること: 実在の会社・物件の特定、売主や仲介会社を悪者にする書き方、恐怖をあおる表現
- 指示文例:
```
【共通ルール】（上記）
型③の投稿を作って。「（架空の例）相場を調べずに中古マンションを申し込み、後で同じエリアの取引価格を見て迷った」という話。
冒頭に「※架空の例です」と書く。誰かを責める表現は使わない。
結論は「申込み前に、同じエリア・同じくらいの築年数の取引価格を見ておく」。X用140字版、Instagramカルーセル5枚版を作って。
```

### 型④ ツールの使い方（画面録画のリール / X動画）
- 目的: ツール利用（クリック）。固定投稿に使う
- 構成: 15〜30秒。①物件ページのスクリーンショットを用意 → ②アップロード → ③参考価格との比較結果 → ④「無料・登録なし（※実際の仕様に合わせる）」
- 注意: 録画に使うスクリーンショットは**架空のダミー画面**を使う（実在ポータルの画面は映さない）。
- 指示文例:
```
【共通ルール】（上記）
型④の30秒リールの台本を作って。お買い得物件チェッカーの使い方を、架空のダミー物件画面で説明する。
秒数ごとに「画面に映すもの／テロップ（15字以内）／ナレーション」を表にして。
最初の2秒で「この価格、相場と比べてどう？」と問いかける。最後は「プロフィールのリンクから」。
ツールの仕様は私（のぼる）が渡す説明の範囲だけで書き、書かれていない機能は書かないで。
```

### 型⑤ 購入時の費用・保険の基礎（note記事＋SNSで告知）
- 目的: アフィリエイト収益。SNSでは記事への誘導だけにし、比較サービスへのリンクはnote記事内に置く
- 構成（記事）: 冒頭に「この記事には広告（アフィリエイトリンク）を含みます」→ 中古住宅購入時にかかる費用の種類 → 火災保険の補償の考え方（一般論）→ 比較サービスの紹介 → 「個別の商品選びは保険会社・代理店に確認」
- 避けること: 特定の保険商品を「これが一番」と推す、保険料の具体額を断定する（保険業法上の募集行為と見られるリスク[10]。判断は専門家に確認：仮説）
- 指示文例:
```
【共通ルール】（上記）
型⑤のnote記事（2,000字程度）の下書きを作って。テーマ「中古住宅を買うときの火災保険、まず知っておく基本」。
冒頭1行目に「※この記事には広告（アフィリエイトリンク）を含みます」。
補償の種類（火災・水災・地震保険など）を一般論で説明し、特定の保険商品を推薦・比較評価しない。保険料の金額は書かない。
比較サービスへのリンクを置く位置を [ここにPRリンク] と示して。最後に「具体的な補償内容は保険会社・代理店に確認してください」。
あわせて、この記事を告知するX投稿（140字、PRリンクは入れずnote記事URLのみ）を作って。
```

### 避けるべき形式（仮説を含む）
- 実在の売出し物件を名指しして「割高」「お買い得」と判定する投稿（売主・仲介会社とのトラブル、画像の無断転載のリスク。仮説）
- 「この物件は○○万円得」など、ツールの参考価格を査定額のように見せる表現（仮説。景品表示法上の優良誤認を避ける趣旨）
- 恐怖訴求（「中古を買うと損する」など）・煽り（仮説）
- 同じ文面・同じリンクの連投（各SNSのスパム扱いのリスク。仮説）
- アフィリエイトリンクだけの投稿（ASP条件・PR表記・保険募集の論点が重なる。仮説）

## (D) 規約・法令チェックリスト（投稿前に毎回）

**ステマ規制・PR表記**
- [ ] 広告主（ASP経由含む）から報酬を得る投稿・記事には「広告」「PR」「プロモーション」等を、見てすぐ分かる位置に書いた（2023年10月1日施行のステマ告示。「広告」「PR」等の記載が認識可能な例として示されている[11][12]）
- [ ] PR表記を大量のハッシュタグに紛れさせていない（運用基準は「明瞭か」で判断[11]）
- [ ] 自分のツールの紹介は自分の投稿として明らか（運営者本人のアカウントであることをプロフィールに明記）。※自社ツールの宣伝自体はステマに当たらないと考えられるが、第三者を装った投稿（別アカウントでの「使ってみた」等）は絶対にしない（仮説）
- [ ] 規制の名宛人は広告主（事業者）だが、ASP・広告主側から表記を求められる前提で運用する[12]

**表示の正確さ（景品表示法・不動産表示の考え方）**
- [ ] 参考価格は「国交省の取引データに基づく目安。査定・鑑定ではない」と書いた
- [ ] 「格安」「掘り出し物」「必ず得」など断定・誇張を使っていない（不動産の表示に関する公正競争規約は宅建業者向けの自主ルールで[13]、本ツールが直接の対象かは未確認。ただし同趣旨で避ける：仮説）
- [ ] データの出典（国土交通省 不動産情報ライブラリ／不動産取引価格情報）を表示した。出典表示の正確な書式は利用規約原文で確認（未確認[14]）

**著作権・他サイトの規約**
- [ ] 不動産ポータル（SUUMO等）の物件写真・画面を転載していない（規約原文は未確認[15]。転載しない前提で運用）
- [ ] 使う画面録画・スクリーンショットはダミーデータ

**保険（アフィリエイト）**
- [ ] 特定の保険商品を推奨・比較評価していない（「情報提供」は募集に当たらないが「特定の保険商品への誘導」は募集に当たり得る、との整理[10]）
- [ ] 案件ごとの提携条件で「SNS掲載可否」「リンク直貼り可否」「表記ルール」を確認した[9]

**各SNSのリンク・アフィリエイト**
- [ ] X: 本文リンク可。リンク付き投稿の扱いは報道が割れている[3][4][5]→UTMで実測。アフィリエイト専用規約はX公式で確認できず（未確認）
- [ ] Instagram: フィード・リールのキャプションURLはクリック不可とされる[16]→プロフィールリンク／ストーリーズのリンクスタンプ（全アカウントに開放[17]）を使う。ハッシュタグは1投稿5個まで（2025年12月から段階適用と報道[18]）
- [ ] Threads: プロフィールリンク最大5件、投稿にリンク可、トピックタグは1投稿1つ[7]
- [ ] YouTubeショート: 説明欄・コメントのリンクはクリック不可[6]→チャンネルプロフィールのリンクを使う
- [ ] note: アフィリエイトは禁止されていないが、禁止行為（コメント欄へのリンク投稿、誇張表現等）があるとされる[19]。原文確認要
- [ ] Yahoo!知恵袋: 宣伝・自サイト誘導の可否が未確認[8]→リンク付き回答はしない

**AI生成画像・動画の表示**
- [ ] Instagram/Threads: AIで作った・大きく加工した写実的な画像は投稿時にAI使用を開示する。Metaは開示またはC2PA等の検出で「AI info」ラベルを付ける[20]
- [ ] YouTube: 実在と見間違える改変・合成コンテンツは開示が必要。アニメーション・台本作成支援・色補正などは対象外とされる[21]
- [ ] TikTok: C2PA付きのAI生成コンテンツは自動で「AI生成」ラベル。有害・誤解を招くAI生成コンテンツはラベルの有無に関わらず禁止[22]
- [ ] 「実在の家・部屋の写真に見えるAI画像」を物件写真として使っていない（誤認防止：仮説）

## (E) 週次で見る指標とUTMの付け方

### UTMの付け方
GA4は大文字小文字を区別するため**すべて小文字**で統一する。`utm_source` にSNS名、`utm_medium=social` とすると既定チャネル「Organic Social」に分類されやすい[23]（正確な分類ルールはGA4公式ヘルプで確認：未確認）。

| 置き場所 | URL例 |
|---|---|
| X 投稿本文 | `https://okaidokucyekka.streamlit.app/?utm_source=x&utm_medium=social&utm_campaign=w1_soba&utm_content=post_body` |
| X 返信にリンク | `...?utm_source=x&utm_medium=social&utm_campaign=w1_soba&utm_content=reply` |
| X 固定投稿 | `...?utm_source=x&utm_medium=social&utm_campaign=pinned` |
| X プロフィール | `...?utm_source=x&utm_medium=social&utm_campaign=profile` |
| Instagram プロフィール | `...?utm_source=instagram&utm_medium=social&utm_campaign=profile` |
| Instagram ストーリーズ | `...?utm_source=instagram&utm_medium=social&utm_campaign=w2_story` |
| Threads | `...?utm_source=threads&utm_medium=social&utm_campaign=...` |
| note 記事内 | `...?utm_source=note&utm_medium=referral&utm_campaign=hoken_kiso` |

- `utm_campaign` は「週番号_テーマ」（例: `w2_checklist`）で統一 → どの型が効いたか分かる
- `utm_content` で「本文リンク」と「返信リンク」を分け、Xのリンク位置の差を実測する

**要確認（技術）**: Streamlit Community Cloud のアプリにGA4タグを入れられるか、またクエリパラメータが計測に渡るかは未確認。入れられない場合の代替: (a) ツール側でクエリパラメータ（utm_source）をログに記録する、(b) 短縮URLサービスのクリック数で代用する（仮説）。

| 区分 | 指標 | 見る場所 | 判断に使う問い |
