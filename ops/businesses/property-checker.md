リポジトリ: https://github.com/chi-pao/-（公開） ／ サイト: https://okaidokucyekka.streamlit.app

> 2026-11-01時点、Claude Codeはこのリポジトリを**読むことだけ**できる（書き込み・テスト実行は権限待ち）。以下はコードを読んで整理した内容で、動作確認はしていない。

## 仕様（コードから整理）

| 項目 | 内容 |
|---|---|
| 目的 | 中古住宅・中古マンション・一戸建ての価格が相場より割安かをチェックする |
| 本体 | `app.py`（Streamlit、約3,900行）。Streamlit Community Cloudで公開 |
| データ | 国土交通省 不動産情報ライブラリAPI（MLIT）の取引価格、住所マスター |
| 価格推定 | 学習済みモデル（LightGBM / scikit-learn）による参考価格。`site-models/` と `models/candidates/` で候補を管理し、検証を通った場合だけ採用 |
| 入力 | 手入力、物件ページのスクリーンショットからOCRで自動入力（`screenshot_ocr/`） |
| 収益化 | A8.netの火災保険アフィリエイトを査定後に表示（有効）。有料プラン・動画広告は実装のみで無効 |
| 計測 | Google Analytics（G-4DZ00D4915） |
| 自動処理（GitHub Actions） | 毎月の学習と安全な採用（`ai_learning.yml`）、6時間ごとの公開サイト確認（`site_health.yml`）、OCRの回帰テスト（複数） |
