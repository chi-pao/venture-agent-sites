# お買い得物件チェッカー 運営チーム（収益化のための担当分け）

決定: 2026-11-03 のぼるさん「SNS運用の分野でいろいろな担当を決めて、収益化を進められる枠組みを作ってほしい。実際の取引価格に近い値を出せるようにする担当も」

目的: 家を買う人・売る人（個人）に使ってもらい、その人とつながりたい会社（売却査定・住宅ローン・保険など）からの成果報酬で収益を得る。

## 担当
| 担当 | 誰が | やること | 成果の数字 |
|---|---|---|---|
| 司令塔 | Claude Code（本体） | 優先順位を決め、各担当の結果をまとめ、のぼるさんに提案・報告する | 月の収益 |
| 収益化 | `monetization-strategist` | A8.net の案件選び（成果条件・確定率・対象エリア）、広告の出し分け（`checker-site/offers.json`）、配置の比較 | 広告のクリック数・成果数・報酬 |
| 集客・検索 | `seo-growth` | 地域の相場ページ（`tools/build_area_pages.py`）・入口ページ・お役立ち記事、Search Console の数字の確認 | 検索からの訪問数 |
| SNS 企画 | `sns-strategist` | 週ごとの投稿計画、型の実験（`ops/sns/EXPERIMENTS.md`）、良かった型を増やす | SNS からの訪問数・反応率 |
| 画像・動画（企画・指示） | `creative-producer` | 画像・動画の企画と ChatGPT への制作依頼書（`ops/chatgpt/outbox/`）。数字が正確でなければならない画像（取引データのグラフ等）は自動で作る | 型ごとの反応率 |
| 画像・動画（制作） | **ChatGPT（チャッピー）** | Claude Code の依頼書どおりにイラスト・キャラクター・動画を作り、承認済みのものを Metricool に予約（流れは `ops/chatgpt/WORKFLOW.md`） | 予約の抜けがないこと |
| 精度改善 | `accuracy-engineer` | 実際の取引価格に近い値を出す。月1回の自動学習（`checker-retrain.yml`）の結果確認、新しい手がかり・計算方法の実験、価格の幅・近くの似た取引の改善 | 2025年以降の取引での誤差中央値・±20%以内の割合 |
| note 連載 | `note-writer` | アプリ作りと収益化の「奮闘記」を週1本下書き（`ops/note/`）。のぼるさんが確認して note に投稿 | note のビュー・売上、note からサイトへの訪問数 |
| 数字の記録 | `data-analyst` | 週1回、訪問数・査定数・クリック・成果・SNS の数字を集めて表にする | 記録の抜けがないこと |
| 品質・法令 | `qa-reviewer` | 投稿・広告・ページの事実確認、PR 表記、景品表示法・A8.net のルール、宅建業法に触れる表現がないか | 差し戻しの件数 |
| 開発 | `product-engineer` | サイトの機能追加・不具合修正（テスト付き） | テストの合格 |
| 承認・契約 | のぼるさん | 提案の承認、A8.net の提携申請、各サービスのアカウント設定 | — |

## 週の流れ
| 曜日 | 内容 |
|---|---|
| 月 | 数字の記録（先週分）→ 司令塔が各担当の次の一手をまとめて、のぼるさんに提案 |
| 火 | のぼるさんの承認 → 投稿の予約、サイトの変更は PR → テスト → 反映 |
| 火〜金 | 投稿（平日18時）。新しい型・広告配置の実験 |
| 金 | 投稿の48時間後の数字を記録 |
| 毎日 | Claude Code が開発日誌（`ops/journal/`）に、やったこと・のぼるさんの言葉・失敗と直し方・数字を書く |
| 日 | 日誌を材料に、note の下書き・SNS の告知文・動画の台本案を自動で作成（月曜にのぼるさんへ） |
| 毎月7日 | 自動学習（精度改善担当が結果を確認し、良くなっていれば入れ替え案を出す） |
| 3か月ごと | 収益・訪問数で、続ける施策と止める施策を決める |

## 決まりごと
- 数字は実際のデータ・実際の査定結果だけ。作った数字・誇張した表現は使わない。広告には「広告・PR」を付ける。
- 人の弱み（返済に困っている等）に付け込む案件は出さない。
- サイトの変更は、のぼるさんが納得した提案だけを本番に入れる（試作用URLで見てもらってから）。
- 新しい広告の追加は `ops/checker/ADD_OFFER.md` の手順（GitHub の画面から追加できる）。
