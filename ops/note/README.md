# note 連載「バツイチ48歳のAI挑戦記」（旧案: AIと作る、お買い得物件チェッカー奮闘記）

題名の形: 【バツイチ48歳のAI挑戦記 #回】その回の中身（のぼるさん 2026-11-04）

決定: 2026-11-03 のぼるさん「アプリを作って収益化を目指す奮闘記を note に自動で書いて、アプリの集客と note の収入も目指したい」

## ねらい
1. **アプリの集客**: 記事を読んだ人がチェッカーを試す（記事内のリンクに `utm_source=note&utm_content=<記事番号>` を付けて数える）。
2. **note の収入**: 無料記事で読者を増やし、ノウハウ部分を有料（1本 300〜500円）またはメンバーシップにする。チップ（サポート）も受け付ける。
3. **信頼**: 「AIに頼って作った個人のアプリ」の正直な記録は、それ自体が読まれる題材。失敗や数字も隠さない。

## 担当
| 作業 | 担当 |
|---|---|
| 連載の計画・記事の下書き（週1本） | Claude Code（`note-writer`） |
| 事実・表記の確認 | Claude Code（`qa-reviewer`） |

| 確認・note への投稿 | のぼるさん（段階1のあいだ） |
| SNS での告知 | VS Code 側の SNS 担当（下の「SNS との分担」） |

## 流れ（毎週）
1. **日曜の夜** 自動の作業（予定の作業）が、その週の出来事（**開発日誌 `ops/journal/`**、`git log`、精度、広告の数字）から `tools/note_facts.py` で「事実メモ」を作り、それだけを材料に次の3つを作る:
   - note の下書き `ops/note/drafts/YYYY-MM-DD-NN.md` と見出し画像・本文中の画像（AI との実際のやりとりの画像を必ず1枚以上）、投稿キット（`tools/note_kit.py`）
   - SNS の告知文3本（**画像は1本ごとに違うデザインにする**：のぼるさん 2026-11-05「表紙のデザインは毎回変えて」。縦 1080×1350。例: 実話の一言を大きく／気持ちの見出し／数字の成績表。作り方は ops/sns/note-promo/images/2026-11-04.html を参考に） `ops/sns/note-promo/YYYY-MM-DD.md`（記事の一番強い一文・AI とのやりとりの一コマ・数字。リンクは `utm_source=<SNS名>&utm_campaign=note`）
   - ショート動画（30秒）の台本案 `ops/chatgpt/outbox/NOTE-VIDEO-YYYY-MM-DD.md`（ChatGPT への依頼書の形）
2. **月曜** Claude Code が下書きを確認し（`qa-reviewer`）、のぼるさんに「今週の記事」として見せる。
3. **のぼるさん** が読んで OK → note に貼って公開（タイトル・本文・ハッシュタグ・有料ラインの位置まで下書きに入れておく）。公開した URL を Claude Code に送る。
4. Claude Code が `ops/note/published/` に記録し、SNS 担当に告知を頼む。
5. 2週間後、note のビュー・スキ・売上と、note からサイトに来た人数を記録する。

## 書き方のルール
- **事実だけ**: 数字（誤差・訪問数・収益）は事実メモにあるものだけ使う。ない数字は書かない。収益は確定したものだけ。
- 名前「のぼる」・年齢「48歳」・「バツイチ」（のぼるさん 2026-11-04）・県名は書いてよい（のぼるさん 2026-11-03）。それ以外の個人のこと（買った値段・仕事・家族）は OK が出たものだけ。下書きでは【要確認】で囲む。
- 地名は都道府県名まで（市区町村・町名は出さない）。
- 文体: 「AI初心者の48歳がつまずいて、直していく」話を、面白おかしく。題名は読みたくなるもの（数字・意外性・失敗）にする。
- 「AIと一緒に作っている」ことは隠さない（連載の売り）。
- 誇大な表現（「必ず儲かる」「プロ並み」等）をしない。アフィリエイトのリンクを入れる回は冒頭に「広告・PRを含みます」と書く。
- 興味を引く型（のぼるさんが参考にした note から 2026-11-03）: ①共感 → ②逆張り（常識をひっくり返す）→ ③問い → ④名前をつける（例「相場の答え合わせ」）→ ⑤実績・数字は後から → ⑥1行1メッセージと余白 → ⑦読者にしてほしい行動は1つだけ。ただし煽り（「今だけ」「必ず」「誰でも稼げる」）は使わない。
- 1本 2,000〜3,500字。見出し3〜5個。最後にチェッカーへのリンクと次回予告。
- 調べて分かったこと（2026-11-05、note 公式ヘルプなど）: 題名の中身は15〜25字ほど（連載名の【】は別）／最初の2行で「何の話か」を言う（SNS に出る部分）／見出しは流し読みでも話が分かるように、多すぎない（2,500字なら6個前後）／最後のお願いは1つ（今はコメント）、サイトのリンクは「※」で添える／見出し画像は毎回入れる。

## 有料化の方針（2026-11-07 司令塔のやりとりで決定。のぼるさん OK と連絡あり。試しの計画）
- 物語の回（連載本編）は、ずっと無料。人を集める役目。サポート（チップ）はオン済み。
- フォロワー30〜50人、または第5回まで出したら（早いほう）→ 有料の記事を1本だけ試す。物語とは別の記事で、中身は「真似できる実物」（例: AI に実際に送った指示文の全部／ChatGPT で遠回りしないための最初の一文）。300〜500円。
- フォロワー100人 → 10本のうち2本くらいを有料に。
- フォロワー300人 → 有料記事をまとめたマガジン（1,000円前後）。
- フォロワー1,000人 → 月額の会員（メンバーシップ）を考える。
- 無料の部分の最後には、毎回お買い得物件チェッカーへのリンク（note で稼ぎながら、サイトにも人を送る）。
- 最初の1本の売れ行きで、値段・中身・時期を見直す。
- 根拠（個人の体験談で、公式の数字ではない）: 目安は「フォロワー100人・無料10本」と言われるが、13人・40人で売れた例も、6,000人で5人の例もある。分かれ目はテーマのはっきりさと SNS の告知。体験談 300〜500円、真似できる手順 500〜1,500円。無料8:有料2 くらい。最初の数か月は月に数百〜数千円の見込み。
