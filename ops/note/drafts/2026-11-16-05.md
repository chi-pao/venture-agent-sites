[目次]

前回、我が家の査定は 803万円でした。

買った値段は 1,780万円。
へこみましたが、分かったこともあります。

**査定の仕組みは、一度作って終わりじゃない。**

## 家の値段は、毎月変わる

アプリの査定は、国が公開している
「実際に、いくらで売れたか」の記録を元にしています。

この記録は、3か月ごとに新しい取引が足されていきます。

つまり、
**作った日から、アプリはどんどん古くなる。**

去年の値段で、今年の家を測っているようなものです。

じゃあ、どうするか。

## 「毎月、勝手に学び直して」

Claude Code に、こうお願いしました。

**「毎月1回、新しい記録を取ってきて、自分で学び直して」**

AI が考えた流れは、こうです。

1. 国の記録から、最新の取引を取ってくる
2. それを使って、査定の仕組みを作り直す
3. 今の仕組みと、どっちがよく当たるか比べる
4. 新しいほうが良ければ、サイトに入れる

[画像: 05-flow.png]

私は寝ているだけ。
……のはずでした。

## 1回目、最後の最後で止まる

1回目。

記録を取ってきて、学び直して、比べるところまでは動いた。

ところが、最後の「サイトに入れる」ところで、エラー。

**最後の最後で、こける。**

2回目。

今度は、
「この仕組みは、変更の案を自分で作れない設定になっています」
と止まる。

……設定？

私には、何のことか分かりません。

こういうとき、私にできることは、ひとつだけです。
**止まった画面を、そのまま AI に見せる。**

Claude Code は、止まった分を代わりに仕上げて、
来月からは止まらないように、設定を直してくれました。

## 52万件、失敗ゼロ

そして、2回目の学び直しの結果。

- 国の記録から取ってきた取引：**約52万件**
- 取ってくるときの失敗：**0回**

査定のズレ（真ん中の値）は、
**22.09% → 21.03%**

実際の値段の ±20% 以内に当たる割合は、
**46.77% → 48.21%**

ほんの少しです。

でも、**私が何もしなくても、少し良くなった。**
これが、毎月続いていきます。

## 「確認しなくていいから、入れて」

最初は、新しい仕組みができるたびに、
「入れていいですか？」と聞かれていました。

でも、数字を見せられても、正直よく分からない。

そこで、こう言いました。

**「そこは確認せずとも、良くなったら採用して」**

ただし、何でも入れていいわけじゃない。
AI と相談して、ルールを決めました。

- ズレが**はっきり小さくなった**ときだけ入れる
- 当たる割合が、**ほとんど悪くならない**こと
- サイトのテストに**合格**すること

この3つを満たしたら、確認なしで入れる。
入れたあとで、結果だけ報告してもらう。

## 任せていいこと、任せないこと

この仕組みを作って、分かったことがあります。

**任せていいのは、「ルールで決められること」。**

良くなったか、悪くなったか。
数字で比べられることは、AI のほうが正確で、早い。

**任せないのは、「何を良しとするか」を決めること。**

どのくらい良くなったら入れるか。
何が悪くなったら止めるか。

そこだけは、自分で決める。
決めてしまえば、あとは毎月、勝手に回ってくれます。

## この回で分かったこと

- 査定の仕組みは、**作った日から古くなる**
- 毎月の学び直しは、AI に**丸ごと任せられる**
- 人が決めるのは「**何を良しとするか**」のルールだけ
