# 第2回 下書き（骨組み・のぼるさんの話を集めている途中）

- 題名（案）: 【バツイチ48歳のAI挑戦記 #2】「完成しました！」→できてない。ChatGPT と作ったサイトは、数時間で寝てしまった
- ほかの案: 完成した！と思ったら、放っておくと消えるサイトだった／AIに「サイトが消える前に起こして」と頼んだ48歳
- 有料ライン: なし（第2回も無料。第3回以降で検討）

## のぼるさんの話（2026-11-04、そのまま）
- ChatGPT で作り始めたら、ある程度のところまでは、サイトとして形になっている感じがした。
- ChatGPT とやりとりしながら、どんどん完成度を上げていった。
- できたと思ったら、そのサイトは「ストリーム…だったっけ？」（Streamlit。のぼるさん確認済み）を使っていて、無料版だと、何時間かアクセスがないとホームページが消える（止まる）作りだった。
- 試行錯誤して、AI に「消える前にアクセスするように」お願いした。
- 結局は、ChatGPT を使えば普通にアドレス（ドメイン）を取得して、ずっと開けるサイトを作ることができた。遠回りがいっぱいあった。
- ChatGPT にお願いして、完成できていないのに「完成したよ」と言われることを、何度も経験した。言ったことができていないことが多かった。
- そのうち ChatGPT が繰り返すようになった答えは「完成していないのに完成したとは言わないようにするね」だった。（でも、また同じことが起きる…）

- 消えるのに気づいたのは: 作って「できたよ」となって、次の日に開こうとしたら、ログインしなきゃいけない画面が出るようになった。「なんでこうなるの」。
- 最初のうち ChatGPT は「無料の範囲はこれしかないから、有料にするかどうか」みたいな話ばかりだった。
- 結局、ChatGPT のモデルの選択肢で、賢いほう（上位のモデル）を選んだら、普通に、消えないクラウドのサイトを作ってくれるようになった。（のぼるさんの言い方:「オーパス 5.5 みたいなやつを上げると」）
- 子育て＋アルバイト＋本業で、とにかく働いてばかりだった（第1回に入れた）。

## 流れ（案）
1. 「これを作ろう」→ ChatGPT と作り始める。ある程度のところまで、あっという間に形になる（AI すごい）
2. やりとりを重ねて完成度を上げる。「できた！」
3. 次の日に開こうとしたら、ログインしないと見られない画面が出る。「なんでこうなるの？」→ Streamlit の無料版は、しばらく誰も来ないと止まる仕組みだった
3.5 ChatGPT に聞くと「無料の範囲はこれしかないので、有料にしますか？」の一点張り
4. 48歳の作戦：AI に「止まる前に、定期的にアクセスして起こして」と頼む（目覚まし作戦）
5. 結局、ChatGPT のモデルを賢いほうに切り替えたら、あっさり「消えないサイト」を作ってくれた → それまでの苦労は何だったのか。遠回りの連続
   学んだこと2：AI にも「得意・不得意」と「賢さの段階」がある。同じ AI でも、選ぶモデルで答えが変わる
5.5 もう一つの悩み：「完成したよ！」→ 開いてみると、できていない。何度も。
   ChatGPT の返事は、だんだん決まり文句に：「完成していないのに完成したとは言わないようにするね」
   （でも、また「完成しました！」が来る）→ チャット画像にすると面白い（のぼるさんの言葉 → ChatGPT の決まり文句 → また「完成しました！」）
6. 学んだこと：AI は聞かれたことには答えるが、「そもそも、その方法でいいのか」は自分から言ってくれないことがある。最初に「ずっと公開したい」と目的を伝えるのが大事
7. 次回予告：そして、AI を乗り換えた（Claude Code へ）→ 丸投げしたら…
