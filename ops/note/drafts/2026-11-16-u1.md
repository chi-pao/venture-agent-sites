[目次]

毎週、note を書いて、投稿する。

書くのは AI が手伝ってくれます。
でも、**貼り付けて、画像を入れて、ハッシュタグを入れて、公開する**。
この作業が、地味に面倒でした。

「これも、AI にやってもらえないか」

そう思って、やってみました。

## 先に結論

できました。

いま、私の note は、こう動いています。

1. AI（Claude Code）が記事を書く
2. 私が読んで「OK」と言う
3. 毎週火曜の夜、パソコンの AI が note を開いて、公開まで済ませる

私がするのは、**読んで OK を出すことと、火曜の夜にパソコンをつけておくこと**だけです。

[画像: u1-flow.png]

## まず知っておくこと：note には「投稿の窓口」がない

最初に調べて分かったのは、
**note には、外の道具から投稿するための公式の窓口がない**ことでした。

ネットには、有志が作った「裏口」の道具もあります。
でも、作った人自身が「規約に触れないかは自己責任で」と書いている。
アカウントが止められたら元も子もないので、使わないことにしました。

そこで選んだのは、
**人と同じように、ブラウザを操作してもらう方法**です。

## 使ったもの

- **パソコンの Claude アプリ**
- **Claude in Chrome**（Chrome の中で、Claude が画面を操作してくれる機能。有料のプランで使えます）
- Claude アプリの**定期タスク**（決まった時間に、Claude が自分で作業を始める機能）

## 手順

**① 投稿するものを、1ページにまとめる**

題名、表紙の画像、本文、本文の中の画像、ハッシュタグ。
これを、コピーしやすい1ページにまとめておきます。
（私は、記事を書く AI に作ってもらっています）

**② パソコンの Claude に頼む**

「このページを開いて、中身を note の下書きに入れて」

これだけで、Chrome が動き出して、
note の画面に、題名や本文が入っていきます。

**③ 定期タスクにする**

同じお願いを、「毎週火曜の夜7時50分」に動くようにしておきます。

**④ やることは、ページに書いておく**

ここが、いちばんのコツでした（理由は下で）。

## つまずいた所

**1. 題名が、勝手に短くされた**

長い題名を入れてもらったら、途中で切られていました。
→ 「題名は省かない」と、はっきり書くようにしました。

**2. 本文の最後の2行が、欠けた**

いちばん大事な、サイトへの案内の行が消えていました。
→ 「最後の行まで入っているか確かめる」を足しました。

**3. ハッシュタグが、入っていなかった**

公開はできたのに、タグがゼロ。
→ 「公開の前に、タグを全部入れる」を足しました。

**4. 予約投稿が、使えなかった**

note の予約投稿は、有料会員だけの機能でした。
→ 予約はやめて、その時間に AI が直接「公開」を押す形にしました。

**5. パソコンの電源が、切れていた**

初めての「毎週の自動公開」の日。
私がパソコンの電源を切っていて、何も起きませんでした。
→ これは AI のせいではありません。火曜の夜はつけておく、と決めました。

## いちばんのコツ：指示は「ページに書いておく」

最初は、直したいことがあるたびに、
私がパソコンの Claude に、新しいお願いを貼っていました。

あるとき、思わず言いました。

**「そもそも、こっちがやらなきゃいけない作業が増えてるよ」**

そこで、やり方を変えました。

パソコンの Claude には、
**「このページを開いて、いちばん上に書いてある指示のとおりにして」**
とだけ頼んでおく。

指示を変えたいときは、ページのほうを書き換える。

これで、私がパソコンにお願いし直すことは、なくなりました。

## この回で分かったこと

- note の投稿は、**ブラウザを操作する AI** に任せられる
- つまずきは、**指示を1行足せば**、だいたい直る
- 指示は**1か所のページにまとめる**と、人の手間が増えない
