# 開発日誌（note・SNS・動画のネタ帳）

決定: 2026-11-03 のぼるさん「これからの変更の記憶ややり取りを元に note の記事を自動作成し、SNS・動画と合わせて集客を増やし収益化を目指す」

- 1日1ファイル `YYYY-MM-DD.md`。Claude Code が、その日の作業の終わりに書き足す。
- 書くこと: やったこと／のぼるさんの言葉（そのまま引用。記事の一番おいしい材料）／失敗と直し方／数字（精度・訪問数・収益）／次にやること。
- 書かないこと: パスワード・APIキー・メールアドレス、のぼるさんが OK していない個人のこと（OK 済み: 名前「のぼる」、48歳、バツイチ、山口県、自宅の購入価格 1,780万円と査定 803万円）。
- 使い道: `tools/note_facts.py` が前回の記事以降の日誌を「事実メモ」に入れる → note の下書き・SNS の告知文・ショート動画の台本案の材料になる。
