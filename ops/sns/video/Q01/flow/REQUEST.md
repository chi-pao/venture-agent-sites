# Google Flow への依頼（値段クイズ 第1回・家族そろい版の作り直し）

のぼるさん 2026-11-08「Flow に課金したから、この形を渡してもっといい感じに変更してもらおうと思う」
Flow は8秒ずつ作るので9本に分ける。文字・曲・最後のチェッカーの紹介は Claude Code があとで入れる。

## すべての場面に共通（毎回いっしょに貼る）
縦長（9:16）。やわらかい立体CG風の、明るい日本のテレビのクイズ番組のセット（青と金色、電球の照明）。
登場人物は添付の絵の家族4人（左から父ケンジ・母ミホ・長男ソウタ・長女ハナ）と、50代の明るい日本人男性の司会者（蝶ネクタイ・ジャケット・マイク）。顔・髪型・服は毎回同じにする。
セリフは日本語で、口の動きをセリフに合わせる。画面に文字・字幕・ロゴは出さない。音楽は入れない（声と小さな効果音だけ）。カメラはゆっくり動かし、揺らさない。実在の人物に似せない。

## 場面
1. 司会者（アップ、楽しそうに）：「値段クイズ！ この家、いくらで売れたでしょう？ A、980万円。B、1800万円。C、2900万円！」
2. 家族4人が解答席で顔を寄せ合って相談（添付：相談の絵）。ソウタが手を挙げて「Aでしょ！ 安そうだもん！」→ ミホがあごに手を当てて「うーん、Bかな」→ ケンジが「Cじゃないか？」
3. 司会者（ためてから、大きく）：「正解は……B！ 1800万円です！」
4. 家族（添付：大喜びの絵 → びっくりの絵）：ミホがガッツポーズで「やった！」、子どもたちも喜ぶ → ケンジが頭に手を当てて「えっ、そんなもんなの？」
5. 司会者：「第2問！ 同じような家で、いちばん高いのは？ 東京、神奈川、大阪！」
6. 家族が相談（添付：相談の絵）：ハナが元気に「とうきょう！」→ ケンジ「東京だろ」→ ミホが首をかしげて「神奈川じゃない？」
7. 司会者：「正解は、神奈川！ 4400万円。東京より、300万円も高いんです！」
8. 家族（添付：びっくりの絵 → 相談の絵）：ケンジが頭に手を当てて「東京じゃないのか！」→ ミホが笑って「数字で見ると、全然ちがうね」→ ケンジがスマホを見て「うちが見てる家も、チェックしてみるか」（スマホの画面は光でぼかす）
9. 司会者（カメラに向かって手を振る）：「何問正解できたかな？ コメントで教えてね！」
