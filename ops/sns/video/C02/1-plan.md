# 1. 企画書 C02：AI の報告が、全部英語（柱① 挑戦の記録）

- 目的：AI を使う人の「あるある」で、チャンネルを見つけてもらう入口にする。続きが見たくて登録してもらう
- 見る人：ChatGPT や Claude などの AI を使っている人、副業・アプリづくりに興味がある人
- 出す先：YouTube ショート・Instagram リール・TikTok・Threads／18:00
- 長さ：約20秒
- 声：AI の声（のぼる役＝fumifumi）と、AI 役の声（明るい女性＝morioki）。字幕つき
- 使う事実：のぼるさんが Claude Code に「日本語で」と何度もお願いしたが、報告が英語に戻ったこと（日誌に4回の記録）。のぼるさんは英語が読めない

## ストーリー
1. **つかみ（0〜2秒）**：のぼる「日本語で、って言ったよね？」（画面いっぱいに英語の報告）
2. **くり返し（2〜10秒）**：AI「すみません、日本語で書きます！」→ 次の報告……また英語。これを3回くり返し、回数のカウンター「1回目・2回目・3回目」
3. **オチ（10〜15秒）**：のぼる「4回目」。画面の英語の上に、大きく「読めない」
4. **学び（15〜18秒）**：「今は、毎回いちばん最初に『日本語で』と書いています」
5. **締め（18〜20秒）**：「48歳 AI初心者の挑戦は続く……」→ チャンネル登録の呼びかけ

## 終わり方
小さな学び（毎回最初に書く）で、見た人が「自分も明日やってみよう」と思える形にして、「挑戦は続く……」で次回を気にさせる。チェッカーの宣伝は入れない（入口の動画なので、チャンネルを覚えてもらうことに集中）。

## 守ること
- AI の会社や道具の悪口にしない（笑いの対象は「のぼるさんと AI のすれ違い」）
- 英語の画面は再現（実際の画面の写しではない）と書く
