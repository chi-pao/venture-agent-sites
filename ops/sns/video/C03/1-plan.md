# 1. 企画書 C03：アプリを作って1か月、もうけと視聴数を全部公開（柱③ 結果報告）

- 目的：正直な数字で「この人がどうなるか見届けたい」と思わせ、チャンネル登録につなげる。毎月の定番にする
- 見る人：副業・AI・個人開発に興味がある人、これまでの動画を見た人
- 出す先：YouTube ショート・Instagram リール・TikTok・Threads／18:00
- 出す日：12月の最初（11月の1か月分の数字がそろってから）
- 長さ：約25秒
- 声：AI の声（のぼる役＝fumifumi）。字幕つき
- 使う事実（すべて実際の数字。作る前にそろえる）：
  - もうけ（収益）：11月末の金額（今のところ 0円）
  - チェッカーに来た人の数：Metricool の Web の数字（11/5 時点は 1か月でページビュー141・訪問112）
  - YouTube の視聴回数：いちばん見られた動画と、いちばん見られなかった動画（のぼるさんの YouTube Studio の画面から）
  - note のビュー・スキ

## ストーリー
1. **つかみ（0〜2秒）**：「アプリを作って1か月。もうけは……」
2. **答え（2〜5秒）**：大きく「0円」
3. **ほかの数字（5〜15秒）**：来た人の数、いちばん見られた動画（「完成しました→できてない」）と、0回だった動画（値段クイズ）を、棒グラフで並べる
4. **気づき（15〜21秒）**：「見られたのは、きれいな動画じゃなくて、失敗の話だった。だから、作り方を変えます」
5. **締め（21〜25秒）**：「来月は、何円になるか。見届けてください」→ 登録の呼びかけ

## 終わり方
「来月はどうなるか」で次回を約束する。数字が悪くても、そのまま出す（正直さが続きを見たくなる理由になる）。

## 守ること
- 数字は実際のものだけ。分からない数字は出さない
- 「もうかる」「稼げる」などのあおりは使わない
