# 見た目の型: 「のぼるの挑戦記」ネオン（2026-11-06 決定）

のぼるさんが VS Code 側のデザインの道具で作り、YouTube のアイコン・バナーに設定したもの。
これまでの地味な作り（文字＋図形だけ）は「ひと目で目に付かない、デザイン性が良いと思えない」（のぼるさん）ので使わない。

## 特徴
- 背景: 黒〜濃い紫。夕日（横じまの入った丸い太陽）と、奥へ続く光る格子の地面（80年代風）
- 光る線（ネオン）: 水色と桃色。文字のふちも光らせる
- ロゴ: 右上がりの矢印＋「のぼる」（桃色の光る太字）。アイコンは水色の光る丸のふち
- 文字: 太く、ふちが光る。白〜桃色

## 使う場所
- YouTube「のぼるの挑戦記」（動画の表紙・始めと終わりの画面）
- note の連載の画像とそろえるかは、note 連載のやりとりで決める
- Instagram・TikTok・Threads・Bluesky のチェッカーの宣伝は、毎回違うデザインの決まりのまま。ただし「ひと目で目を引く」「デザインとして良い」を条件にする
