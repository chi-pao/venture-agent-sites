## 紹介文の型（体験・価格は書かない）
```
【こういう人に】〇〇で困っている人
【確かめること】サイズ（幅・奥行き・高さ）／洗えるか／素材
【レビューで多い声】〇〇（商品ページのレビューから。数字は商品ページにある物だけ）
#冬じたく #収納
```
- 書いてよい: 商品ページにある仕様、レビューでよく見る声（「〜という声が多い」）、向いている人。
- 書かない: 「使ってみた」「買ってよかった」「最安」「No.1」「絶対」、効果・効能、価格。

## 毎週の流れ
1. 月〜木: 毎朝の候補づくり（`threads_plan.py`）の見本ページに出る「楽天ROOM に載せる候補」から選ぶ。
2. Claude Code が上の型で紹介文を作る → のぼるさんが OK。
3. のぼるさんの Chrome（楽天にログイン済み）で載せる:
   商品ページの「ROOMに投稿」の itemcode（`ショップ:番号`）→ `https://room.rakuten.co.jp/mix?itemcode=ショップ:番号` → コメント欄に文 → 「完了」→ コレクションに入れる。
4. 金: 数字を `ops/metrics/` に記録。
