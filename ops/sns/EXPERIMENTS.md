# SNS の型の実験記録

方針（のぼるさん 2026-11-03）: インパクトがあるもの・分かりやすいものを、いろいろな型で試し、集客が良かった型を増やす。問いかけの型が良さそうなので、インパクト系の画像をメインにする。

## 測り方
- 投稿のリンクに `utm_campaign=w<週>` と `utm_content=<型>` を付け、サイトに来た人数を型ごとに比べる（Metricool の Web の数字）。
- SNS 側の数字（表示・いいね・リポスト・リンクのクリック）を投稿の48時間後に記録する。
- 判断の目安: リンクのクリック数（なければ反応の数）÷ 表示数。

## 翌週の配分
- 約5割: 前週いちばん良かった型
- 約3割: 良かった型の言い回し・色・数字を変えたもの
- 約2割: まだ試していない型
