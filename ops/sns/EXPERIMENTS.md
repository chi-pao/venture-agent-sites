# SNS の型の実験記録

方針（のぼるさん 2026-11-03）: インパクトがあるもの・分かりやすいものを、いろいろな型で試し、集客が良かった型を増やす。

## 測り方
- 投稿のリンクに `utm_campaign=w<週>` と `utm_content=<型>` を付け、サイトに来た人数を型ごとに比べる（Metricool の Web の数字）。
- SNS 側の数字（表示・いいね・リポスト・リンクのクリック）を投稿の48時間後に記録する。
- 判断の目安: リンクのクリック数（なければ反応の数）÷ 表示数。

## 翌週の配分
- 約5割: 前週いちばん良かった型
- 約3割: 良かった型の言い回し・色・数字を変えたもの
- 約2割: まだ試していない型

## 型の一覧
| 型 | 中身 | 初回 |
|---|---|---|
| question | 「この家、○○万円。高い？安い？」を大きく（紺の背景） | W1-1 |
| number | 実際の査定の差（例 −398万円）を大きく | W1-2 |
| steps | 使い方を3つの手順で | W1-3 |
| checklist | 買う前に確かめる3つ | W1-4 |
| verdict | 判定の3段階と計算式 | W1-5 |
| trust | 査定のしくみ（データ・検証・計算・料金） | 未 |
| compare | 価格を変えて比べる（2つの結果を並べる） | 未 |
| character | ケンジ一家のイラスト＋ひとこと | 未 |
| video-screen | 実際の画面の操作を録画した短い動画 | 準備中 |
