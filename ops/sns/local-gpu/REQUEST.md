# のぼるさんのパソコン（RTX 4070 SUPER・12GB）で、リアルな AI 動画を作るための依頼

依頼する相手: のぼるさんのパソコンの VS Code の Claude Code
依頼した人: SNS・動画の担当（クラウドの Claude Code）／承認: のぼるさん（2026-11-17「グラボは入ってるよ」「RTX4070 SUPER だった」）
返事・説明はすべて日本語で。英語を一語も混ぜない。

## 目的
値段クイズなどの動画を、今より「人が自然に動いて、日本語の声に口がきちんと合う」ものにする。
クラウドの作業場所には画像処理の部品がなく、口まわりしか動かせないため、のぼるさんのパソコンの RTX 4070 SUPER（12GB）を使う。

## まず試すこと（1場面だけ）
1. 下の2つの道具を、のぼるさんのパソコンに入れる（ComfyUI のポータブル版でまとめて動かすのがおすすめ）
   - **Wan 2.2（TI2V-5B か I2V）**：1枚の絵から、人が自然に動く数秒の動画を作る。Apache 2.0（お金のからむ使い方も可）
   - **口の動きを声に合わせる道具**：LatentSync か MuseTalk。**入れる前に、お金のからむ使い方が許されているか（本体と、中で使う部品の決まり）を確かめ、だめなものは使わない**
2. 材料（GitHub の chi-pao/venture-agent-sites）
   - 絵: `ops/sns/characters/avatar/family-consult.png`（家族4人・相談）
   - 声: 値段クイズ第2回のケンジのセリフ「いや、Aじゃないか？」 → クラウド側で作った声のファイルを `ops/sns/local-gpu/test/05.wav` に置いてある
3. やること
   - 絵から5秒ほどの「家族が相談している」動きの動画を作る（顔は正面を向いたまま、カメラは動かさない）
   - その動画のケンジの口を、05.wav の声に合わせる
   - できた動画を `ops/sns/local-gpu/test/out-05.mp4` として、ブランチに push する（main へのプルリクエストを作って取り込んでよい）
4. 決まり
   - 実在の人物の写真は使わない。文字・数字は入れない（文字は クラウド側で入れる）
   - 使った道具の名前・版・決まり（ライセンス）を `ops/sns/local-gpu/TOOLS.md` に書く
   - 1つの道具の入れ方で30分以上つまずいたら、無理をせず止めて、何ができて何ができなかったかを日本語で書く
   - 入れる物の大きさ（ハードディスクの空き）を先に確かめ、50GB 以上空いていなければ、のぼるさんに聞いてから進める

## うまくいったら
クラウドの SNS・動画の担当が、場面ごとの依頼（絵・声・長さ）をこのフォルダに置く → パソコンで動画にする → クラウド側で文字・曲・チェッカーの紹介を入れて仕上げる。

## 動画を作る手順（2026-11-19 から必ず守る）
動画は `ops/sns/templates/VIDEO-PROCESS.md` の順番（1.企画書 2.キャラクターシート 3.背景シート 4.絵コンテ 5.動画作成）で作る。パソコンで作るときも、1〜4 の書類を読んでから 5 に入る。書類がなければ、作る前にクラウドの SNS・動画の担当に頼む。
