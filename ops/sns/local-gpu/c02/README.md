## 指示の中身（日本語にしたもの）
共通: 「暗い夜の部屋でノートパソコンの前に座る1歳の赤ちゃんの顔のアップ。顔は画面の青い光で照らされる。カメラは動かさない。体・肩・手は動かさず、表情だけが変わる。ぼけた暗い背景は変えない。やわらかい立体CG風、なめらかで自然な動き」
してほしくないこと: カメラの動き・ゆれ・ちらつき・形の崩れ・体や手の動き・背景の変化・文字・ロゴ・顔の崩れ・別の子・大人になる・ほかの人・ぼやけ・速い動き・泣く

| 表情 | 表情ごとの指示 |
|---|---|
| ふつう | 落ち着いて画面を見つめる。口は閉じたまま。ときどきまばたき。ほんの少し首をかしげる |
| 驚く | 目がまんまるに開き、まゆが上がり、口が小さな「お」の形にあく。頭が少しだけ後ろに引く |
| 怒る | すねて不機嫌になる。まゆが寄り、ほっぺがふくらみ、口をとがらせる。画面の光が少し赤っぽくなる |
| 呆れる | 無表情でしらけた顔。上のまぶたがゆっくり半分まで下がり、まゆはそのまま、口は閉じて一文字、鼻から小さくため息をつき肩が少し下がる。痛そうな顔ではない |
| ほっとした笑顔 | 目が細くなってやさしく笑い、ほっぺが上がり、にっこり笑う |

## 作り直したところ
- **呆れる**: 1回目（seed 42）は目をぎゅっと細めて、痛そうな顔に見えた → 指示を「無表情でしらけた顔」に変えた2回目（seed 7）を採用。まぶたが半分下がって口が一文字になった。
- **怒る**: 3回作った。
  - 1回目（seed 42）: 表情はいちばん良い（まゆが寄って口をとがらせる）。ただ、2秒すぎから顔が**真っ赤**に照らされた（依頼は「少し赤っぽく」）。
  - 2回目（seed 7、赤い光をやめる指示）: 赤くはならないが、目をぎゅっとつぶった泣き顔に近くなった。
  - 3回目（seed 123、目を開けたままにらむ指示）: にやっと笑ったように見えてしまった。
  - → **1回目を採用し、明るさ（表情）はそのままで、色だけを最初のコマの青い光に戻した**（`settings/fix_red.py`）。そのため怒るの動画は赤みがない。赤みを足すなら、仕上げのときにクラウド側で少し色を重ねてほしい。目のまわりにわずかに黄色っぽさが残るところがある。

## 見てわかったこと
- 5本とも、顔・服・よだれかけ・部屋は元の絵のままで、別の子には見えない。カメラも背景も動いていない。
- ふつう は、途中から少し下（画面）を見る目になる。
- 驚く は、最後の1秒で口が閉じて、もとの顔に戻りかける。驚いた顔を見せるなら前半4秒を使うのがよい。
