# 事業スタジオ

AI が「お金になりそうなアプリ」を考え、勝てるかを調べ、**ある程度の品質のアプリになるまで自動で作ります**。
のぼるさんがするのは、最後に完成品を見て決めることだけです。

- **続ける** … 事業として独立させて進める
- **ブラッシュアップ** … 直す点を伝えて、もう一度作り直す
- **やめる** … 理由は次の企画に生かす

あわせて、今ある SNS で発信する部門と、楽天アフィリエイトで物を売る部門もあります。
以前の仕組みから何を残し・省き・直したかは [仕分け表.md](仕分け表.md) にあります。

## 部門

| 部門 | すること |
|---|---|
| ①企画部 | ネットで「お金を払ってでも解決したい困りごと」を探し、アプリの案を6つ出して点数を付ける |
| ②市場・競合部 | 似たアプリの値段・弱点・口コミを調べ、勝てるか・伸びるかを判断する |
| ③審査部 | わざと反対の立場から、法律・採算・集客・作れるかを厳しく見る。通れば開発へ |
| ⑤開発部 | アプリを作る（紹介ページ・料金ページ・登録の入口・支払いの練習版まで） |
| ⑥品質部 | 開発部とは別に、実際に動かして検査する。だめなら開発部が自動で直す（2回まで） |
| ⑦公開部 | スマホでも見られる確認用ページを公開する（検索には出ない） |
| ⑧SNS運用部 | 今ある SNS の投稿案を作る。「のぼるの挑戦記」の毎週の投稿も作る |
| ⑨数字・学習 | やめた理由・実際の数字を、次の企画に生かす |
| ⑩物販・アフィリエイト部 | 今の SNS で売れそうな楽天の商品テーマを考え、商品まとめページと PR 付きの投稿案を作る |

SNS の投稿は全部「承認待ち」で今の依頼一覧（`ops/tasks/queue.json`）に入ります。のぼるさんが OK したものだけ、今までどおり ChatGPT が画像・動画にして Metricool で予約します。

## 流れ

```
①企画 → ②市場・競合 → ③審査 → ⑤開発 ⇄ ⑥品質 → ⑦確認用ページ → ⑧SNS案
                                                         ↓
                                  のぼるさんへお知らせ（最終確認.md）
                                                         ↓
                              続ける ／ ブラッシュアップ ／ やめる
```

## はじめにやること（1回だけ）

1. Claude Code の CLI を入れて、今の契約でログインする（各部門はこの契約の中で動くので、追加の料金はかかりません）。
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
   ```bash
   claude
   ```
2. studio フォルダーで点検する。
   ```bash
   py studio.py doctor
   ```
3. 必要なら `config.json` に書き足す（なくても動きます）。
   - `discord_webhook_url`：お知らせをスマホの Discord で受け取る
   - `signup_url`：事前登録や問い合わせの受け口（Googleフォームなど）
   - `rakuten_app_id`・`rakuten_affiliate_id`：楽天の商品を自動で探してリンクを作る（楽天ウェブサービスで無料登録）

## 使い方

| やりたいこと | コマンド |
|---|---|
| アプリを考えて、最後まで作る | `py studio.py run` |
| 一覧を見る | `py studio.py list` |
| 完成品の資料を見る | `py studio.py show 番号` |
| 続ける | `py studio.py decide 番号 continue` |
| ブラッシュアップ | `py studio.py decide 番号 brushup --note "直す点"` |
| やめる | `py studio.py decide 番号 kill --note "理由"` |
| 挑戦記の今週の投稿案 | `py studio.py sns` |
| 楽天アフィリエイトの企画 | `py studio.py affiliate` |
| 実際の数字を記録 | `py studio.py metrics 番号 --visits 訪問 --signups 登録 --revenue 売上円` |
| 全部まとめて自動で進める | `py studio.py auto` |

`studio.cmd` を使えば `studio run` のようにも書けます。

`auto` は、毎日動かす前提のコマンドです。直しの依頼や作りかけを先に進めます。前回の企画から7日たっていれば、新しく企画します。ただし、のぼるさんの判断待ちが3件以上あるときは、新しく作るのを休みます。SNS と楽天の企画は週1回です。
毎日朝7時に動かすなら、タスク スケジューラに登録します（登録するかは、のぼるさんが決めてから）。
```bash
schtasks /create /tn "事業スタジオ" /tr "C:\場所\venture-agent-sites\studio\studio.cmd auto" /sc daily /st 07:00
```

## 作られるもの（`studio/data/`。GitHub には上げません）

| 場所 | 中身 |
|---|---|
| `BOARD.md` | 全部の案と「のぼるさんの番」 |
| `INBOX.md` | お知らせ |
| `ideas/番号/最終確認.md` | 最後に見る資料（見る場所・収益の見込み・心配な点・検査の結果・決め方） |
| `ideas/番号/build/` | 作ったアプリ |

楽天の商品まとめページは `picks/` に作られ、GitHub に反映すると `https://venture-agent-sites.pages.dev/picks/…` で公開されます。
