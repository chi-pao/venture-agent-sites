# SNS と物販の進め方

今の数字（2026-11-05）：どの SNS もフォロワー0人、収益0円。
アプリごとにゼロから人を集めるのは大変なので、次の3本立てにします。すべて今あるアカウントを使います。

| 柱 | 中身 | 場所 | 担当 |
|---|---|---|---|
| ① 挑戦記 | AI が今週考えた案、落ちた理由、作ったアプリ、売上（0円も正直に） | YouTube「のぼるの挑戦記」・note・Threads | ⑧SNS運用部（毎週） |
| ② アプリの宣伝 | 「続ける」と決めたアプリを使う人に役立つ投稿 | アプリに合う SNS | ⑧SNS運用部（続けると決めたとき） |
| ③ 物販 | 楽天アフィリエイトで、見る人に合う商品を「選び方」として紹介 | YouTube ショート・TikTok・Threads・Instagram | ⑩物販・アフィリエイト部（毎週） |

## ③ 物販で売れそうな方向（AI が毎週見直します）

| 見る人 | 合う商品 | 投稿の型の例 |
|---|---|---|
| お買い得物件チェッカーに来る人（家を買う・売る） | 引っ越し用品・収納・家具・防災・住まいの手入れ | 「新居で最初に買う3つ」「買う前に測るところ」 |
| 挑戦記を見る人（AI・副業に興味） | パソコン作業の道具・AI や副業の本 | 「AIでアプリを作る机の道具」 |
| 季節 | 引っ越しシーズン、年末の大掃除、防災の日 | 時期に合わせて先回り |

リンクの扱い：
- 投稿のリンクは、自分の「商品まとめページ」（`picks/`、PR 表記つき）に飛ばします。楽天のリンクはそのページに置きます。こうすると、どの SNS から来たかを UTM で数えられ、価格の書き方や PR 表記もページ側でそろえられます。
- TikTok は投稿文のリンクが押せないので、プロフィールのリンクからまとめページへ案内します。
- YouTube は説明欄と固定コメントにまとめページのリンクを置きます。

守ること：
- すべての投稿の最初に「PR」を入れます（ステマ規制）。
- 価格は「◯月◯日時点」と書きます。
- 健康食品・化粧品・医薬品の効果は言いません。
- 「最安」「No.1」は書きません。

## 毎週の流れ（今の流れに足すだけ）

| 曜日 | 内容 |
|---|---|
| 毎日朝 | `auto` が開発を進め、必要なら企画。挑戦記と物販の投稿案は週1回作る |
| 月 | のぼるさんが投稿案を見て OK（文・画像・リンクを全部見せる、今の決まりどおり） |
| 火〜日 | ChatGPT が画像・動画を作り、Metricool で予約（今の流れ） |
| 金 | 数字の記録（今の担当）。アプリの数字は `metrics` でも入れる |

## のぼるさんにお願いしたいこと（どれも無料。登録は本人が行うもの）

| もの | 何に使うか |
|---|---|
| 楽天アフィリエイトのアフィリエイトID | 紹介リンクを自動で作る |
| 楽天ウェブサービスのアプリID | 商品を自動で探す |
| Discord の通知先 | 最終確認のお知らせをスマホで受け取る |
| 事前登録の受け口（Googleフォームなど） | アプリへの関心を数える |
